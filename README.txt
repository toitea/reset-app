RESET prototype

Open index.html on a computer to preview.

To install it like an app on Android/iPhone, upload these files to an HTTPS host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages. Then open the site on each phone and choose Add to Home Screen / Install App.

Current version:
- Two profiles: Toya and Him
- Morning pulls
- Mood-based card pulls
- Cheat Day pulls
- Shared Us deck
- Secret Missions
- Craving/Rough Moment support
- Wins saved locally on each phone
- Offline cache after first hosted load

Not yet included:
- Real accounts
- Real-time syncing between both phones
- Push notifications
- Shared completion status
Those require a backend such as Firebase or Supabase.
